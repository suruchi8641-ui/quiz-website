
# QuizMaster - Online Quiz Website

**Developed by: Suruchi Kumari**

## About the Project

QuizMaster is an interactive online quiz website developed using HTML, CSS, and JavaScript. It helps users test their knowledge of web development through multiple-choice questions, score tracking, and timed quizzes.

This project is created for learning and demonstrating front-end web development skills as part of an internship project.

## Features

- Modern and responsive user interface
- Multiple-choice questions
- HTML, CSS, and JavaScript quiz categories
- Easy, Medium, and Hard difficulty levels
- Automatic score updates
- Countdown timer for each question
- Progress bar to track quiz completion
- Instant feedback for answers
- Final score and percentage calculation
- Correct and incorrect answer statistics
- Quiz restart functionality
- Recent quiz results and best score tracking
- Browser-based result storage using localStorage
- Mobile-friendly design

## Technologies Used

- **HTML5:** Structures the webpage and quiz interface.
- **CSS3:** Provides styling, responsive layouts, and visual effects.
- **JavaScript:** Handles quiz logic, timers, score calculation, and result history.
- **GitHub:** Stores and manages the project source code.
- **GitHub Pages:** Publishes the website online.


## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Choose a quiz category and difficulty level.
5. Click **Start Quiz**.
6. Answer the questions and view your final result.

No additional libraries or backend server are required.
